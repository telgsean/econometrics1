Exercise 1

In this exercise, we are investigating the invariance property of the maximum likelihood estimator. Consider the simple linear regression model \[ y_{i} = \beta_{1} + \beta_{2}x_{i} + u_{i}, \] where \(u_{i}\) are i.i.d. draws from the standard normal distribution. Suppose we are interested not only in the intercept and slope, but also in the expected value of \(y_{i}\) whenever \(x_{i} = c\), for some constant \(c\). Define the following reparameterization: \[ \begin{aligned} &\theta_{1} = \beta_{1} + c\beta_{2}, \\ &\theta_{2} = \beta_{2}. \end{aligned} \]

  1. Express the original regression model in terms of the new parameters \(\theta_{1}\) and \(\theta_{2}\).
  2. Derive the maximum likelihood estimators of \(\beta_{1}\) and \(\beta_{2}\) using the original parameterization.
  3. Derive the maximum likelihood estimators of \(\theta_{1}\) and \(\theta_{2}\) directly, using the reparameterized model.
  4. Show that the maximum likelihood estimator of \(\theta_{1}\) obtained in c. is identical to the estimator obtained by transforming the original maximum likelihood estimators in b. In other words, verify that \(\hat{\theta}_{1} = \hat{\beta}_{1,ML} + c \hat{\beta}_{2,ML}\).
  5. Explain why this result illustrates the invariance property of the maximum likelihood estimator.
CautionShort solution

  1. The reparameterization gives \(\beta_{1} = \theta_{1} - c\theta_{2}\) and \(\beta_{2} = \theta_{2}\). Thus, the reparameterized regression becomes \[ \begin{aligned} y_{i} &= \theta_{1} - c\theta_{2} + \theta_{2}x_{i} + u_{i} \\ &= \theta_{1} + \theta_{2}(x_{i} - c) + u_{i}. \end{aligned} \] This is simply a regression of \(y_{i}\) on a shifted explanatory variable \(x_{i} - c\).

  2. Since the variance is known to be one, the maximum likelihood estimator coincides with the least-squares estimator in both parameterizations. For the original parameterization: \[ \hat{\beta}_{2,ML} = \frac{\sum_{i=1}^{n}(x_{i} - \overline{x})(y_{i} - \overline{y})}{\sum_{i=1}^{n} (x_{i} - \overline{x})^{2}}. \] and \[ \hat{\beta}_{1,ML} = \overline{y} - \hat{\beta}_{2, ML} \overline{x}. \]

  3. For the reparameterized model, the intercept estimator is given by \[ \hat{\theta}_{1,ML} = \overline{y} - \hat{\theta}_{2, ML}(\overline{x} - c). \] The slope estimator is \[ \hat{\theta}_{2,ML} = \frac{\sum_{i=1}^{n}[(x_{i} - c) - (\overline{x} - c)](y_{i} - \overline{y})}{\sum_{i=1}^{n} [(x_{i} - c) - (\overline{x} - c)]^{2}}. \]

  4. Simplifying the expression for \(\hat{\theta}_{2,ML}\) gives \(\hat{\theta}_{2,ML} = \hat{\beta}_{2,ML}\). It follows that \[ \begin{aligned} \hat{\theta}_{1,ML} &= \overline{y} - \hat{\beta}_{2,ML} (\overline{x} - c) \\ &= \overline{y} - \hat{\beta}_{2,ML}\overline{x} + c\hat{\beta}_{2,ML} \\ &= \hat{\beta}_{1,ML} + c\hat{\beta}_{2,ML}. \end{aligned} \]

  5. Let \(\beta = (\beta_{1},\beta_{2})'\). The invariance property states that if \(\hat{\beta}\) is the maximum likelihood estimator of \(\beta\), then \(g(\hat{\beta})\) is the maximum likelihood estimator of \(g(\beta)\), provided \(g(\hat{\beta})\) exists. In b., we establish that \(\hat{\beta}_{ML}\) is the maximum likelihood estimator of \(\beta_{ML}\). In our reparameterization in c., we calculate the maximum likelihood estimator \(\hat{\theta}\) of \(\theta\) in the new model directly. In d., we show that the estimator \(\hat{\theta} = (\hat{\theta}_{1}, \hat{\theta}_{2})' = (\hat{\beta}_{1} + c\hat{\beta}_{2}, \hat{\beta}_{2})' = g(\hat{\beta})\) is the maximum likelihood estimator of \(\theta = (\theta_{1}, \theta_{2}) = (\beta_{1} + c\beta_{2}, \beta_{2})' = g(\beta)\). This is exactly what invariance entails.

Exercise 2

Consider the linear regression model \[ y = X\beta + u, \] where \(u \sim N(0, I_{n})\). We want to estimate \(\beta\) subject to the restrictions \(R\beta = r\).

  1. Set up the Lagrangian \(L(\beta)\). What are the dimensions of the objects in the Lagrangian?

  2. Show that the first-order conditions are given by \[ \begin{cases} (X'y - X'X\tilde{\beta})' &= \tilde{l}'R \\ R\tilde{\beta} &= r \end{cases} \]

  3. Use the first-order conditions to write \[ \tilde{l} = (R(X'X)^{-1}R')^{-1}(R\hat{\beta} - r), \] and continue by showing that \[ \tilde{\beta} = \hat{\beta} - (X'X)^{-1}R'(R(X'X)^{-1}R')^{-1}(R\hat{\beta} - r). \]

CautionHint

This exercise is a simplified version of the derivations in Section 4.8.

Exercise 3

Suppose that we want to estimate the linear model \(y \sim \N(X\beta, \sigma^{2}I_{n})\) by maximum likelihood. The density of \(y\) is given by \[ f(y; \beta, \sigma^{2}) = (2\pi)^{-n/2}|\sigma^{2}I_{n}|^{-1/2} \exp -\frac{1}{2}(y - X\beta)'(\sigma^{2} I_{n})^{-1} (y - X\beta). \] There are two additional pieces of information. Firstly, we want to estimate the model subject to a single linear restriction on \(\beta\). Secondly, there is no need to estimate \(\sigma^{2}\). We may assume that the error term has unit variance, i.e. \(\sigma^{2} = 1\), which heavily simplifies the problem. Assumptions (2.1) - (2.4) hold.

  1. Show that, in the current setup, the loglikelihood can be written as \[ \log L (\beta; y) = -\frac{n}{2}\log(2\pi) - \frac{1}{2}(y-X\beta)'(y - X\beta). \]

  2. Explain why the outcomes of restricted maximum likelihood and restricted least squares are exactly the same in this setup.

  3. Set up the Lagrangian function and show that the first-order conditions are given by (i) \((X'y - X'X\tilde{\beta})' = \tilde{\lambda}w'\) and (ii) \(w'\tilde{\beta} = r\).

  4. Show that solving the set of equations yields the restricted estimator \(\tilde{\beta} = \hat{\beta} - (X'X)^{-1}w(w'(X'X)^{-1}w)^{-1}(w'\hat{\beta} - r)\).

Suppose that the unconstrained model is the simple linear regression model on which we want to impose the restriction that the intercept is zero. That is, we consider \(X = (\imath : x)\), where \(x = (x_{1}, \ldots, x_{n})'\), with \(w'\beta = (1, 0) \begin{pmatrix} \beta_{1} \\ \beta_{2} \end{pmatrix} = 0 = r\).

  1. Show that the restricted estimator in this case can be written as \[ \tilde{\beta} = \begin{pmatrix} \tilde{\beta}_{1} \\ \tilde{\beta}_{2} \end{pmatrix} = \begin{pmatrix} 0 \\ \hat{\beta}_{2} + \frac{\imath'x}{x'x}\hat{\beta}_{1} \end{pmatrix}. \] Hint: Write out the expression for \(\tilde{\beta}\) derived in d. for the current setup. It helps to first determine the different terms that \(\tilde{\beta}\) is composed of. For example, you can find that \(w'(X'X)^{-1}w = \frac{x'x}{n x'x - (\imath'x)^{2}}\).
CautionHint

  1. If \(\sigma^{2} = 1\), then \(|\sigma^{2}I_{n}|^{-1/2} = 1^{-1/2} = 1\) and \((\sigma^{2} I_{n})^{-1} = I_{n}\). Thus, \[ L(\beta, \sigma^{2} = 1; y) = (2\pi)^{-n/2} \exp -\frac{1}{2}(y - X\beta)'(y - X\beta). \] Taking the natural logarithm yields \[ \log L (\beta, \sigma^{2} = 1; y) = -\frac{n}{2}\log(2\pi) - \frac{1}{2}(y-X\beta)'(y - X\beta). \]

  2. Since \(\sigma^{2} = 1\) is known, the only unknown parameter (vector) is \(\beta\). The loglikelihood can be written as a constant term \(-\frac{n}{2}\log(2\pi)\) minus the term involving \(\beta\), i.e. \(\frac{1}{2}\phi(\beta)\), where \(\phi(\beta) = (y - X\beta)'(y - X\beta)\). We note that minimizing \(\phi(\beta)\) or maximizing \(-\frac{1}{2}\phi(\beta)\) w.r.t. \(\beta\) yields exactly the same solution for \(\beta\). The inclusion of a single linear restriction of the from \(w'\beta = r\) in the objective function does not change that.

  3. The Lagrangian is given by \[ \begin{aligned} \psi(\beta) &= -\frac{n}{2}\log(2\pi) - \frac{1}{2}(y-X\beta)'(y - X\beta) - \lambda(w'\beta - r) \\ &= -\frac{n}{2}\log(2\pi) - \frac{1}{2}(y'y - 2y'X\beta + \beta'X'X\beta] - \lambda(w'\beta - r). \end{aligned} \] The derivative of \(\psi(\beta)\) w.r.t. \(\beta\) is given by \[ \frac{\partial \psi(\beta)}{\partial \beta'} = -\frac{1}{2}(-2y'X + 2\beta'X'X) - \lambda w'. \] Setting this derivative equal to zero and adding the restriction yields the first-order conditions (i) \((X'y - X'X\tilde{\beta})' = \tilde{\lambda}w'\) and (ii) \(w'\tilde{\beta} = r\).

  4. From the first-order conditions we can derive \[ X'X\tilde{\beta} = X'y - \tilde{\lambda}w \Rightarrow \tilde{\beta} = (X'X)^{-1}X'y - \tilde{\lambda}(X'X)^{-1}w. \] By recognizing \(\hat{\beta} = (X'X)^{-1}X'y\), we obtain \(\tilde{\beta} = \hat{\beta} - \tilde{\lambda}(X'X)^{-1}w\). Using this result in the second equation yields \[ w'\tilde{\beta} = r \Rightarrow r = w'\tilde{\beta} = w'(\hat{\beta} - \tilde{\lambda}(X'X)^{-1}w) = w'\hat{\beta} - \tilde{\lambda}w'(X'X)^{-1}w. \] Thus, \(\tilde{\lambda} = (w'(X'X)^{-1}w)^{-1}(w'\beta - r)\), which yields \[ \tilde{\beta} = \hat{\beta} - \tilde{\lambda} (X'X)^{-1}w = \hat{\beta} - (X'X)^{-1}w(w'(X'X)^{-1}w)^{-1}(w'\hat{\beta} - r). \] Note that \(X'X\) is invertible as Assumption 2.2 holds. Moreover, \(w'(X'X)^{-1}w\) is a scalar and its inverse exists (as we may safely assume that the trivial case \(w = 0\) can be excluded).

  5. In case of the simple linear regression model, we have \[ X'X = \begin{pmatrix} n & \imath'x \\ \imath'x & x'x \end{pmatrix}, \] where we recognize that \(\imath'\imath = n\). The inverse of \(X'X\) is given by \[ (X'X)^{-1} = \frac{1}{n x'x - (\imath'x)^{2}} \begin{pmatrix} x'x & -\imath'x \\ -\imath'x & n \end{pmatrix}. \] We can compute the following quantities: \((X'X)^{-1}w = \begin{pmatrix} \frac{x'x}{n x'x - (\imath'x)^{2}} \\ -\frac{\imath'x}{n x'x - (\imath'x)^{2}} \end{pmatrix}\), which gives \(w'(X'X)^{-1}w = \frac{x'x}{n x'x - (\imath'x)^{2}}\), as only the first element is selected out of the vector, and \(w'\hat{\beta} - r = \hat{\beta}_{1}\). Putting this information together yields \[ \tilde{\beta} = \begin{pmatrix} \tilde{\beta}_{1} \\ \tilde{\beta}_{2} \end{pmatrix} = \begin{pmatrix} \hat{\beta}_{1} \\ \hat{\beta}_{2} \end{pmatrix} - \begin{pmatrix} \hat{\beta}_{1} \\ \left(-\frac{\imath'x}{n x'x - (\imath'x)^{2}} / \frac{x'x}{n x'x - (\imath'x)^{2}} \right) \hat{\beta}_{1} \end{pmatrix} = \begin{pmatrix} 0 \\ \hat{\beta}_{2} + \frac{\imath'x}{x'x}\hat{\beta}_{1} \end{pmatrix}. \]

Exercise 4

To test the hypothesis \(R\beta = r\) in the linear regression model \(y = X\beta + u\) with \(E(u) = 0\) and \(\Var(u) = \sigma^{2}I_{n}\), we can use the \(F\)-test, but also the Wald (W), the Lagrange Multiplier (LM) and the Likelihood Ratio (LR) test.

  1. Why are the LM and LR test only applicable in the maximum likelihood framework?
  2. Explain the main intuition behind the W, LM and LR tests.
  3. What is the difference between the \(F\)-test and the Wald test?
CautionSolution

  1. The LR test consists of the log-likelihood function, evaluated at both the restricted and unrestricted estimator. The LM test is based on the score evaluated at the restricted estimator. Note that these tests are thus relying on the assumption of normality (of the error term).

  2. The Wald test is based on the idea that \(R\hat{\beta}\) should be close to \(r\) under the null hypothesis. The LM test makes use of the fact that \(q(\hat{\beta}) = 0\) (remember: that is how we found the estimators!) and under the null hypothesis, \(q(\tilde{\beta})\) should be close to zero. That is, if the restrictions \(R\beta = r\) hold, then the model estimated under the restriction should perform well, and thus its corresponding score should also be close to zero. The likelihood ratio test immediately compares the log-likelihoods of the model with and without the restrictions imposed. If the null hypothesis holds, then the log-likelihood values should not be too different.

  3. We have \[ F = \frac{(R\hat{\beta} - r)'(R(X'X)^{-1}R')^{-1}(R\hat{\beta} - r)/m}{s^2}, \] and \[ W = \frac{(R\hat{\beta} - r)'(R(X'X)^{-1}R')^{-1}(R\hat{\beta} - r)}{\hat{\sigma}^2}, \] where \(s^{2} = e'e/(n-k)\), \(\hat{\sigma}^{2} = e'e/n\) and \(m\) the number of restrictions imposed (the number of rows in \(R\)). Thus, we can write \[ W = \frac{m s^2 F}{\hat{\sigma}^{2}} = \frac{nm}{n-k} F. \] Under the null hypothesis \(R\beta = r\), we have \(F \sim F(m, n-k)\). For large \(n\), \(W \approx mF\) and \(F \approx \chi^{2}(m)/m\), where \(\approx\) means ‘is approximately equal to’. Together, these facts imply thst \(W \approx \chi^{2}(m)\). In essence, the two tests are the same. The Wald test is just the asymptotic approximation to the \(F\)-test.

Exercise 5

Prove the inequalities \[ LM \leq LR \leq W, \] for testing a linear hypothesis in the linear model \[ y = X\beta + u. \] Make use of the expressions \[ LM = \frac{ng}{n-k+gF}F, \quad LR = n\log\left( 1 + \frac{g}{n-k}F \right), \quad W = \frac{ng}{n-k}F, \] which express the Lagrange Multiplier (LM), Likelihood Ratio (LR) and Wald (W) test in terms of the \(F\)-test.

CautionSolution

We prove the inequalities one by one. We start by proving \(LR \leq W\). It follows that \[ LR = n \log\left( 1 + \frac{g}{n-k} F \right) = n \log \left(1 + \frac{W}{n}\right), \] by combining the expressions of \(LR\) and \(W\). Thus, proving \(LR \leq W\) is equivalent to showing \(n \log \left(1 + \frac{W}{n}\right) \leq W\). Let \(w = W/n\), then we have to prove that \(\log(1 + w) \leq w\) for all \(w \geq 0\), or equivalently, that the function \(f(w) = w - \log(1 + w) \geq 0\) for all \(w \geq 0\). Because \(f(0) = 0\), it suffices to show that the first derivative is non-negative. That is, \[ \frac{d f}{dw} = 1 - \frac{1}{1+w} = \frac{w}{1+w} \geq 0 \qquad \mbox{ for all } w \geq 0. \] Hence, this shows that \(LR \leq W\).

We continue to prove \(LM \leq LR\). We have shown that \(LR = n \log (1 + w)\) with \(w = W/n\). Let us also express \(LM\) in terms of \(w\): \[ LM = \frac{ngF}{n-k+gF} = \frac{ngF/(n-k)}{1+gF/(n-k)} = \frac{W}{1+\frac{W}{n}} = n \frac{w}{1+w}. \] Thus, proving \(LM \leq LR\) is equivalent to showing $ (1 + w)$ for all \(w \geq 0\). That is, we have to prove that \(g(w) = \log(1+w) - \frac{w}{1+w} \geq 0\) for all \(w \geq 0\). As \(g(0) = 0\), it suffices to show that the first derivative is non-negative. That is, \[ \frac{d g}{dw} = \frac{1}{1+w} - \frac{(1+w)-w}{(1+w)^{2}} = \frac{w}{(1+w)^{2}} \geq 0 \qquad \mbox{ for all } w \geq 0. \] Hence, this shows that \(LM \leq LR\). Combining \(LR \leq W\) and \(LM \leq LR\) leads to the desired result \(LM \leq LR \leq W\).

Least squares and measures of fit

Exercise 1

Let \(b = (X'X)^{-1}X'y\), and let \(e = y - Xb\) be the vector of residuals and \(\hat{y} = Xb\) the vector of predictors. Show that:

  1. \(\widehat{y}\) and \(e\) are orthogonal to each other.
  2. \(\widehat{y} = Py\) and \(e = My\), where \(P\) and \(M\) are symmetric idempotent matrices satisfying \(MP = 0\).
  3. \(y'y = \widehat{y}'\widehat{y} + e'e\).
  4. \(Ae = e\) if and only if the regression contains a constant term; more precisely, if \(\imath\) is a linear combination of the columns of \(X\).
  5. \(y'Ay = \hat{y}'A\hat{y} + e'e\), if the regression contains a constant term, which we usually write as \(\text{SST} = \text{SSE} + \text{SSR}\).
CautionShort solution
  1. \(\widehat{y} = Xb\), so \(\widehat{y}'e = b'X'e\), now \(X'e = 0\) by first order conditions of least squares. One can see this explicitly by substituting \(y - Xb\) for \(e\) and writing it out.
  2. \(\widehat{y} = Xb = X(X'X)^{-1}X'y\), so \(P = X(X'X)^{-1}X'\) and thus \(M = I_{n} - P\). It is easily verifiable that \(P\) is, just like \(M\), symmetric and idempotent (which we already showed in class). Note that \(MP = (I_{n} - P)P = P - PP = P - P = 0\), as \(P\) is idempotent.
  3. Write \(y = \widehat{y} + e\) and note that it is a decomposition (that is what you showed in the first subquestion).
  4. Note that \(Ae = e\) if and only if \(\imath'e = \imath'My = 0\), which occurs if and only if \(M\imath = 0\).
    • If \(\imath\) is a linear combination of columns in \(X\), then \(\imath = Xc\) for some \(c\) and indeed \(MXc = 0\) as \(MX=0\).
    • Conversely, if \(M\imath = 0\), then writing out this equation yields \(\imath = X(X'X)^{-1}X'\imath\), which is a linear combination of the columns of \(X\).
  5. Since \(Ae = e\) and \(\hat{y}'e = 0\) (orthogonality), one immediately gets the desired result in the same way as in c.

Empirical applications

Exercise 2

Suppose that a researcher, using data on class size (CS) and average test scores from 50 third-grade classes, obtains the following least squares output: \[ \widehat{Testscore} = 640.3 - 4.93 \times CS. \]

  1. A classroom has \(25\) students. What is the prediction for that classroom’s average test score?
  2. Last year a classroom had \(21\) students, and this year it has \(24\) students. What is the regression’s prediction for the change in the classroom’s average test score? Is this prediction reliable? Motivate your answer.
  3. The sample average of the class sizes across the 50 classrooms is \(22.8\). What is the sample average of the test scores across the \(50\) classrooms? Hint: Use the least-squares approximator of \(\beta_{1}\).
CautionSolution
  1. \(\widehat{Testscore} = 640.3 - 4.93 \times 25 = 517.05\).
  2. Similarly as in a., we can compute: \[ \begin{aligned} &\widehat{Testscore} = 640.3 - 4.93 \times 21 = 536.77, \\ &\widehat{Testscore} = 640.3 - 4.93 \times 24 = 521.98, \end{aligned} \] which are the predicted test scores for \(CS = 21\) and \(CS = 24\), respectively. The predicted change is then \(521.98 - 536.77 = -14.79\). Note that this predicted change of \(-14.79\) in test score is not reliable. If the number of students is the only aspect that changes, we want to know the effect of increasing class size from \(21\) to \(24\), while keeping all other relevant factors fixed. This is the ceteris paribus interpretation. Ideally, we would therefore use a model such as \[ TestScore = \beta_1 + \beta_2 CS + \beta_3 QualityOfTeacher + \beta_4 QualityOfMaterial + \cdots + u^{*}. \] In this model, \(\beta_2\) measures the expected change in test score associated with a one-student increase in class size, holding the other factors fixed. Therefore, increasing class size from \(21\) to \(24\) students corresponds to an estimated change of \(3\hat{\beta}_2\). In the simple regression \[ TestScore = \beta_1 + \beta_2 CS + u, \] the error term \(u\) contains factors such as teacher quality and material quality. If these factors are correlated with class size, then \(u\) is correlated with \(CS\). For example, if larger classes tend to have worse teachers and worse materials, the negative relationship between class size and test scores partly reflects these other factors. The simple regression therefore cannot isolate the ceteris paribus effect of class size. Thus, the estimate \(-14.79 = 3\hat{\beta}_2\) from the simple regression should not be interpreted as the expected change in test score when an otherwise identical classroom goes from \(21\) to \(24\) students. It reflects the observed relationship between class size and test scores, which may also capture systematic differences in teacher quality, materials, and other factors between classrooms.
  3. Note that \[ \hat{\beta}_{1} = \overline{y} - \hat{\beta}_{2}\overline{x}, \] which can be rewritten to \[ \begin{aligned} \overline{y} &= \hat{\beta}_{1} + \hat{\beta}_{2}\overline{x} \\ &= 640.3 - 4.93 \times 22.8 = 527.90. \end{aligned} \]

Exercise 3

A regression of average weekly earnings (\(AWE\), measured in dollars) on age (measured in years) using a random sample of college-educated full-time workers aged \(25-65\) yields the following output: \[ \widehat{AWE} = 696.7 + 9.6 \times Age. \]

  1. Explain what the coefficient values \(696.7\) and \(9.6\) mean.
  2. What does the regression predict will be the earnings for a \(25\)-year-old worker? And for a \(45\)-year-old worker?
  3. Will the regression give reliable predictions for a \(99\)-year-old worker? Why (not)?
  4. The sample average of age is \(41.6\) years. What is the sample average of \(AWE\)?
  5. What are the unit of measurements for \(R^{2}\) and \(SER\)?
  6. Given what you know about the distribution of earnings, do you think it is plausible that the distribution of errors in the regression is normal?
CautionShort solution
  1. The intercept has no intuitive meaning, as there are no workers with age equal to zero years. The estimated slope is the average difference in expected earnings between person \(A\) and \(B\), where person \(A\) is one year older than person \(B\).
  2. \(936.7\) and \(1128.7\), respectively.
  3. No, because the regression model is estimated only including workers aged \(25-65\).
  4. \(1096.06\) (can be solved similarly as in Exercise 1).
  5. \(R^{2}\) is unit-free (but is often expressed as a percentage, as it is restricted to the \([0,1]\) interval). Note that both \(SSE\) and \(SST\) are measured in \(dollar^{2}\), i.e. the squared unit of the dependent variable \(Y\). The unit of measurement of the \(SER\) is dollars; it has the same unit of measurement as the dependent variable \(Y\).
  6. The errors likely have a right-skewed distribution, because there are some persons with relatively high earnings, whereas no persons have negative earnings (assuming no self-employed persons with large losses). The kurtosis (fatness of the tail) is also expected to be larger than under the normal distribution due to this.

Exercise 4

In a course on microeconomics, you have seen the Cobb-Douglas production function \[ Q = \alpha K^{\beta_{1}}L^{\beta_{2}}, \] where \(Q\) denotes output, \(K\) is capital, and \(L\) is labor. We wish to estimate \(\alpha\), \(\beta_{1}\), and \(\beta_{2}\) based on \(n\) observations on \((Q_{i}, K_{i}, L_{i})\). How can this be done?

CautionHint

Is this nonlinear equation a linear model is disguise? If yes, how can you linearize it?

Exercise 5

A researcher wants to estimate the following model \[ y = \beta_{0} + \beta_{1}x_{1} + \beta_{2}x_{1}^{2} + u, \] because she believes that \(x_{1}\) does not have a constant marginal effect on \(y\) but rather a diminishing marginal effect.

  1. Does the proposed model violate the linearity assumption?
  2. An advantage of the multiple linear regression model is that it facilitates ceteris paribus analysis. Why is this difficult here?
  3. In case of diminishing marginal effects, what would be the signs of \(\beta_{1}\) and \(\beta_{2}\)?
  4. Determine how a change in \(x_{1}\) affects \(y\). At which value of \(x_{1}\) does the function take its maximum?
  5. Given an example of an empirical application where this modeling technique might be appropriate.
CautionHint
  1. No.
  2. Can you change \(x_{1}\) while controlling (i.e. keeping fixed) \(x_{1}^{2}\)?
  3. \(\beta_{1} > 0\) and \(\beta_{2} < 0\) gives a parabola with inverted \(U\)-shape when we plot \(y\) against \(x_{1}\).
  4. Define \(g(x_{1}) = \beta_{0} + \beta_{1}x_{1} + \beta_{2}x_{1}^{2}\) and proceed to take the appropriate derivative. Set it equal to zero and solve for \(x_{1}\).
  5. A well-known example is the relationship between experience and salary. Argue why.

Residuals

Exercise 6

Consider the standard linear regression model \(y = X\beta + u\), where \(y\) and \(u\) are of order \(n \times 1\), \(\beta\) is of order \(k \times 1\), and \(X\) is an \(n \times k\) matrix with full column rank. We assume that \(E(u) = 0\) and \(\Var(u) = \sigma^{2} I_{n}\).

  1. Show that the least-squares residuals \(e\) are equal to \(My\) and \(Mu\).
  2. Compute the mean and variance of the residuals \(e\).
  3. Show that the variance matrix of \(e\) cannot have full rank and explain why.
CautionSolution
  1. The residuals are defined as \(e = y - X\hat{\beta}\) with \(\hat{\beta} = (X'X)^{-1}X'y\). Therefore, \[ \begin{aligned} e &= y - X(X'X)^{-1}X'y = (I_{n} - X(X'X)^{-1}X')y \\ &= My = M(X\beta + u) = Mu, \end{aligned} \] since \(MX = (I_{n} - X(X'X)^{-1}X')X = X - X = 0\). This also implies that \(X'e = X'Mu = 0\).
  2. The mean of \(e\) is given by \[ E(e)= E(Mu) = ME(u)=0, \] and the variance of \(e\) can be computed as \[ \Var(e) = \Var(Mu) = M \Var(u) M = \sigma^2 M, \] where we used the fact that \(M\) is symmetric and idempotent.
  3. There are \(k\) linearly independent restrictions on the residuals, namely \(X'e = 0\), as shown in a. Given these constraints, the variance of \(e\) cannot have full rank. In fact, the rank is reduced by the number of linearly independent restrictions, as we can also see from \[ r(\Var(e))= r(\sigma^2 M) = r(M) = \text{tr}(M) = n-k, \] as we have shown before. We like to think of \(e\) as a predictor of \(u\), but this is only partly successful, because \(\Var(u)\) is nonsingular, while \(\Var(e)\) is singular, since \(k\) degrees of freedom are lost when we estimate \(\beta\).

Assumptions

Exercise 7

Determine whether linear regression is warrented for the following models:

  1. \(y_{i} = \beta_{1}x_{1,i} + \sqrt{\beta_{2}}x_{2,i} + u_{i}\)
  2. \(y_{i} = \beta_{1}x_{1,i} + \beta_{2} x_{1,i}^{2} + u_{i}\)
  3. \(y_{i} = \beta_{1}x_{1,i} + \beta_{2}x_{2,i} + \beta_{3}x_{1,i}x_{2,i} + u_{i}\)
  4. \(y_{i} = \beta_{1} \exp(\beta_{2}x_{1,i})u_{i}\) for \(\beta_{1} > 0\), \(u_{i} >0\), \(y_{i} > 0\) for all \(i\).
CautionHint

The model needs to be linear in the parameters. If need and possible, rewrite the model to make it linear.

Exercise 8

For the following models, argue whether it is possible that \(X\) is collinear.

  1. \(y_{i} = \beta_{1} + \beta_{2}x_{i} + u_{i}\).
  2. \(y_{i} = \beta_{1} + \beta_{2}\text{North}_{i} + \beta_{3}\text{South}_{i} + \beta_{4} \text{West}_{i} + \beta_{5}\text{East}_{i} + u_{i}\), where \(y_{i}\) is the wealth in city \(i\) and \(\text{North}_{i} = 1\) if the city is located in the North, and vice versa for the other regressors. Each city can only belong to one cardinal direction.
  3. \(y_{i} = \beta_{1} + \beta_{2}\text{Full-Time}_{i} + \beta_{3}\text{Part-Time}_{i} + u_{i}\), where \(y_{i}\) is productivity of employee \(i\) who is either a full-time or part-time worker.
  4. \(y_{i} = \beta_{1} + \beta_{2}x_{i} + \beta_{3} x_{i}^{2} + u_{i}\).
CautionHint

It may help to write out how the \(X\) matrix would look like (you can make up some data yourself).

Best unbiased estimation

Exercise 9

Let \(\widehat{\theta}_{1}\) and \(\widehat{\theta}_{2}\) be two uncorrelated unbiased estimators of a parameter \(\theta\) with variances \(\sigma_{1}^{2}\) and \(\sigma_{2}^{2}\), respectively. What linear combination \[ \widehat{\theta} = w_{1} \widehat{\theta}_{1} + w_{2} \widehat{\theta}_{2} \] is the best unbiased estimator of \(\theta\)?

CautionSolution

Since \(\widehat{\theta}_{1}\) and \(\widehat{\theta}_{2}\) are unbiased estimators of \(\theta\), we have \[ \begin{aligned} E(\widehat{\theta}) &= w_{1} E(\widehat{\theta}_{1}) + w_{2} E(\widehat{\theta}_{2}) \\ &= w_{1}\theta + w_{2}\theta \\ &= (w_{1} + w_{2})\theta, \end{aligned} \] and since they are uncorrelated, we have \[ \begin{aligned} \Var(\widehat{\theta}) &= w_{1}^{2}\Var(\widehat{\theta}_{1}) + w_{2}^2 \Var(\widehat{\theta}_{2}) \\ &= w_{1}^{2}\sigma_{1}^2 + w_2^{2}\sigma_{2}^2. \end{aligned} \] As \(\widehat{\theta}\) must be unbiased, we have \(w_1 + w_2=1\). Thus, we need to minimize \[ \phi(w_1)=w_{1}^{2}\sigma_{1}^2 + (1-w_1)^{2}\sigma_{2}^2. \] Differentiating with respect to \(w_1\) gives \[ \phi'(w_1)=2w_{1}\sigma_{1}^2 - 2(1-w_{1})\sigma_{2}^2. \] Setting the derivative to zero and solving gives \[ w_{1}^{*} = \frac{\sigma_{2}^2}{\sigma_{1}^2 + \sigma_{2}^2}. \] This is indeed a minimum, because \(\phi''(w_1) = 2(\sigma_{1}^2 + \sigma_{2}^2) > 0\). Hence, the linear combination \[ \widehat{\theta} = \frac{\sigma_{2}^2}{\sigma_{1}^2 + \sigma_{2}^2}\widehat{\theta}_{1} + \frac{\sigma_{1}^2}{\sigma_{1}^2 + \sigma_{2}^2}\widehat{\theta}_{2} \] is the minimum variance unbiased estimator of \(\theta\). For example, if \(\sigma_{1}^2 = 1\) and \(\sigma_{2}^2 = 3\), then \(w_{1} = 3/4\) and \(w_{2} = 1/4\), and the variance of \(\widehat{\theta}\) is \((3/4)^{2} \times 1 + (1/4)^{2} \times 3 = 3/4\), which is smaller than the variances of \(\widehat\theta_1\) and \(\widehat\theta_2\).
